# 跳跃诊断

在现有 `g1_vmd_2_eval.py` 验证命令末尾添加 `--jump_diagnostics`。
普通 H5 验证和 `--deployment_bundle` 均支持，不需要重新训练。
不开启此开关时，不添加传感器、不安装采样钩子、不输出诊断文件。

默认记录环境 0 的整段 rollout，每轮单独输出到：

`output/jump-diagnostics/episode_<编号>_<时间>/`

- `overview.png`：参考/实际根节点高度、垂直速度、左右脚接触法向力、脚部连杆原点高度、双脚无接触指示。
- `legs.png`：各腿部关节参考角度、控制目标、实际角度，以及计算力矩、施加力矩、配置力矩限制。
- `samples.csv`、`samples.npz`：原始采样，CSV 列名包含单位；NPZ 为 `columns` 和 `values`。
- `metadata.json`：模型/参考来源、种子、频率、关节顺序、平滑系数、结束原因等。

可选参数：

| 参数 | 默认值 | 用途 |
|---|---|---|
| `--jump_diagnostics_dir` | `output/jump-diagnostics` | 输出根目录 |
| `--jump_diagnostics_env` | `0` | 记录哪个并行环境 |
| `--jump_diagnostics_start` | `0` | 从 rollout 第几秒开始记录 |
| `--jump_diagnostics_end` | 不限 | 记录到第几秒 |
| `--jump_contact_threshold` | `5` | 判断脚部接触的力阈值，N |

例如只记录第 10 至 15 秒：在原验证命令末尾添加
`--jump_diagnostics --jump_diagnostics_start 10 --jump_diagnostics_end 15`。
这仅裁剪采样范围，仿真仍从原始起点运行，不会跳过准备动作。

建议单环境、固定 seed、`--num_episodes 1`、保持 `--action_smooth_alpha 1.0`。
普通验证保留奖励与观测扰动；`--play` 会改变验证条件，比较模型时要保持一致。
诊断会增加同步与绘图开销，不应据此评估推理性能或实时性。
导出部署包和仅推理 benchmark 模式不能开启跳跃诊断。

## 采样与解释

在每次 scene 物理更新后、终止判定和自动 reset 前采样，避免将失败后的重置站姿混入曲线。
支持每物理步更新 scene 的后端；对内部合并 decimation 的后端明确拒绝，避免把控制步数据误标为物理步数据。
停止、正常结束、提前终止和退出时都保存已采集的数据。退出时需让 Python 执行清理；强制杀进程无法保证保存。

参考角度/高度采用产生当前控制目标的控制步参考，在子步内保持；`ref_time_s` 给出参考时刻，
`time_s` 是当前物理样本的 rollout 时刻。参考垂直速度由相邻控制步的参考高度差分计算，
它是运动学要求，不代表参考动作一定满足动力学。

脚部传感器选取 `left/right_ankle_roll_link`，报告该连杆的聚合法向接触力，包含自碰撞，
并非仅地面反力。双脚低于阈值仅是无接触候选，必须结合脚部高度和根节点运动判断腾空。
脚部高度为连杆原点相对项目平地高度，不是脚底净空；根节点高度也不是全身重心高度。
配置力矩限制并不等于速度相关的电机瞬时输出上限，饱和应结合计算/施加力矩差及关节速度判断。
本工具面向当前平地舞蹈环境，不用于复杂地形净空测量。

## 回归检查

`python source/train_workflow/scripts/test_jump_diagnostics.py`

CPU 测试覆盖每控制步多个物理样本、自动重置前状态保留、空闲/时间窗口排除、接触判断、
CSV/NPZ/PNG 输出和采样钩子恢复。真实接触与执行器数值仍需在 Isaac 场景运行验证。

## 片段筛选与解释

报告自动增加 `analysis.json`、`analysis.md` 和 `segment_review.png`。
使用 2 秒窗口、0.5 秒步长，按持续高度跟踪误差和关节目标跟踪误差筛选复看候选，
不再用参考高度峰值判断跳跃失败。候选阈值为本轮相对分位数与绝对误差下限的较大者，
属于排查顺序，不是经标注验证的分类器。

对现存报告可运行 `source/train_workflow/scripts/analyze_jump_diagnostics.py <报告目录>`，
重复添加 `--window "标签:起始秒:结束秒"` 指定问题与正常对照片段。
用户标注与自动候选分别保存，不把用户标注当作自动检测结论。

每段同时给出高度 RMSE、95% 绝对误差、参考/实际高度范围、无接触比例与最长连续时间、
目标/参考角度 RMS、实际/目标角度 RMS、力矩裁剪比例。
高度互相关只提供 ±0.3 秒范围内的时滞候选；平坦、低相关或搜索边界结果不作时滞结论。
正值表示实际落后；周期性动作可能歧义，且参考控制步保持带来约一个控制步的时序不确定性。
校正前后 RMSE 必须比较相同重叠区间，不能直接与全窗口 RMSE 比较。

现有记录缺少参考双脚接触标签及参考足部轨迹，不能判断应当何时腾空，
也不能把无接触时间更长自动视为更好。目标/参考 RMS 没有方向信息，不能据此认定
残差抵消起跳动作。必须结合关节方向、接触时序和视觉复看后再决定奖励改动。
