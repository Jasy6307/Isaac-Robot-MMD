# 第三轮整理前源码快照

`sources.zip` 逐字节保存本轮 15 个脚本，ZIP 内使用原仓库相对路径；`catalog.json` 登记路径、SHA-256 与原行数。归档不属于日常命令发现范围，不增加一批可运行的历史 `.py` 文件。

运行复现使用保留的原入口，或按 [G1 工具导航](../../train_workflow/scripts/README.md)、[PMX 工具导航](../../pmx_prototype/tools/README.md)、[角色诊断导航](../../pmx_prototype/diagnostics/README.md) 选择正式实现。压缩内容供审阅及回归对照；不要直接在归档目录执行，因为旧代码根据原目录深度定位项目。

业务实现文件按 7→3（G1 离线诊断）、3→2（旧腿部处理）、2→1（角色预览）、3→1（睦缓存检查）统计，共 15→7，减少 8 个分散实现。另有 15 个兼容入口、1 个新增 G1 诊断调度入口，及 2 个新增回归测试文件，均分别计数，不冒称物理文件总数减少 8 个。

本轮未更改在运行的 balanced 训练、采样/验收核心、低速探针、配置、认可动作或视频。CPU 测试用合成遥测和本归档对照；资产测试显式依赖本机已认可的角色 USD/PMX 与 G1 H5，测试生成物放临时目录，六份认可动作另跑原资产回归。
